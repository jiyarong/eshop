# 05 销售漏斗

## 目标

用统一口径判断 SKU 总漏斗，再定位具体 Listing 的流量或转化问题。

## 研发任务

1. 日期范围默认最近四个完整周，对比期为紧邻等长上一周期。
2. SKU 四周期标准漏斗：访问、加购、加购率、下单、加购到下单率、成交、访问到成交率、净销量。
3. 加购率 = 加购/访问；加购到下单率 = 下单/加购；访问到成交率 = 成交/访问。
4. SKU 比例汇总各 Listing 分子分母后重算，只放跨平台可严格映射字段。
5. Listing 漏斗显示公共字段和平台特有字段；默认正在经营，按当期成交降序，首屏最多 10 个。
6. Listing 日趋势默认八周和访问、加购率、加购到下单率；每图只查询对应 Listing 事件，并通过 03 的公共 `events` target 与 `applyOperationEventMarkLines` 绘制事件竖线，不在 05 内拼 ECharts `markLine`。
7. 首屏只懒加载前 3 个 Listing 图表，其余展开加载。

## 验收

- [ ] SKU 转化率不是 Listing 转化率平均值。
- [ ] Listing 筛选不改变 SKU 汇总边界。
- [ ] 平台无字段、无数据、零分母可区分。
- [ ] 未绑定订单不进入成交和净销量。
- [ ] 对比期、平台差异、零访问和硬关联测试通过。
