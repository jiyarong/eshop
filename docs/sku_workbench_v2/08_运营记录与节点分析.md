# 08 运营记录与节点分析

## 目标

围绕单 Listing，把价格、广告、送仓动作与漏斗、销量、利润放在同一时间轴观察，保留原始审计。

## 研发任务

1. 筛选平台、店铺、Listing、时间，默认八周；默认当期成交最高的经营 Listing，无成交则选有库存者。
2. 动作摘要直接读取现有 `Ec::OperationAction`，支持价格、广告、送仓分类；人工备注沿用现有权限和弹窗。
3. 单 Listing 趋势可选客户成交价、后台定价、佣金、平台补贴、净销量、周平均利润和事件；默认成交价、后台价、周平均利润。事件竖线统一接入 03 的公共 ECharts 标记能力，不在 08 内重复实现 `markLine`。
4. 历史定价不完整时标数据起点；平台补贴无权威公式则隐藏。
5. 节点表按日展示动作、后台价、成交价、访问、三种转化、净销量、广告费/占比、周平均利润。
6. 同日多动作全部展示，无动作日期仍保留；周指标明确标注粒度。
7. 不输出因果结论。
8. 原始 Log 位于底部并默认折叠，保留来源、操作人、diff 和分页。

## 验收

- [ ] 默认 Listing 规则正确。
- [ ] 客户成交价来自硬关联订单实际支付。
- [ ] 事件全部来自现有 `Ec::OperationAction`，同日多动作不丢失。
- [ ] 日与周指标粒度清晰，页面无因果文案。
- [ ] 历史缺失、无 Listing、跨周及跨 SKU 权限测试通过。
