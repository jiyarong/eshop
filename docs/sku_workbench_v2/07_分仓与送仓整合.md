# 07 分仓与送仓整合

## 目标

在分仓视图直接查看集群库存、补货和断货，并将原送仓 Tab 降为排查区域。

## 研发任务

1. 保留店铺、商品/集群视图和目标库存天数；店铺只限当前 SKU 有效绑定。
2. 沿用 WB/Ozon 仓库查询，展示库存状态、覆盖、预测日销、28 天销量、可售、预留、在途、新增发货和缺口。
3. 集群增加最后补货日期/数量、预计断货和实际断货区间。
4. 最后补货按内部 SKU、平台、店铺和集群关联；同店多 Listing 合并，不要求精确归属 Listing。
5. 预计断货 = 快照日 + 可售/预测日销，仅日销大于零时计算并标为估算。
6. 实际断货由日快照连续为零判断，阈值使用 00 结论。
7. 集群展开显示最近 10 次补货并可定位送仓单。
8. 将原 `supply_orders` 筛选、字段、分页迁入底部排查区。
9. 分仓建议仅预留目标集群、数量、理由、时间和状态接口。

## 验收

- [ ] 补货不跨内部 SKU、店铺或集群串联，同店多 Listing 按合并口径展示。
- [ ] 零日销不计算预计断货，实际断货只读真实快照。
- [ ] 计划仓、实际仓、部分收货和快照断档测试通过。
- [ ] 送仓字段、筛选、分页及旧 URL 无回归。
