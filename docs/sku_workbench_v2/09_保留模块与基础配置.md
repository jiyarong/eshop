# 09 保留模块与基础配置

## 目标

在新结构中稳定迁移广告、搜索词、Ozon Chat 和基础配置，避免既有能力回归。

## 研发任务

1. 广告保留 Ozon/WB 现有日期、店铺和平台差异；可归属数据继续供利润和运营模块使用。
2. 搜索词保留自然周、词、店铺、SKU 大盘及明细，不做结构重构。
3. Ozon Chat 保留店铺和会话，验证 Tab Frame 内导航与返回。
4. 基础配置分基础信息、商品属性、平台绑定、附件。
5. 负责人展示现有开发和运营关联，不只显示 `owner_name`。
6. 绑定复用 `shared/_sku_product_bindings`；附件复用 `shared/_attachments` 及现有安全规则。
7. 时间使用 `display_time`，新增文案补齐全部 locale，同页组件使用唯一 DOM ID。

## 验收

- [ ] 四模块在整页和抽屉均可访问。
- [ ] 广告、搜索词、Chat 筛选无回归。
- [ ] 开发/运营负责人正确。
- [ ] 商品绑定和附件只能操作当前 SKU。
- [ ] 附件预览、上传、编辑、删除权限及 I18n 测试通过。
